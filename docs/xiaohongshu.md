## 本次提交的作品

只上传 `release/wild-window-xiaohongshu.zip`。建议表单名称：**全球动物观察挑战**；建议 Slogan：**六条线索，认识动物**。

ZIP 中的实际作品是离线文字观察小游戏：每局六轮，根据线索在三个动物名称中选择答案，随后查看正确答案和动物知识，最后显示得分与观察记录，并可重新开始。涉及大象、斑马、长颈鹿、信天翁、大熊猫和麋鹿；轮次与选项会打乱，无倒计时。

作品无需申请相机、麦克风、定位、屏幕共享或剪贴板权限。它尝试使用本地存储保存最佳成绩，存储不可用时仍可继续游戏。参赛介绍与笔记应明确这是离线猜动物游戏，不应把桌面版的直播、截图或 AI 识别写成本小工具的能力。

## 平台限制

[官方容器规范（更新于 2026-08-11）](https://fe-video-qc.xhscdn.com/fe-platform-file/104101b8323q4m0uaga06277180ac7t8006ptl0e12ek1g)：

- [官方上传指南](https://www.xiaohongshu.com/explore/6a8fe753000000001e0159f7)确认：**每次上传单个 ZIP，大小不超过 10 MB**。
- 必须完全离线，不能请求外网、加载外部图片/字体、嵌入 iframe/object。
- HTML、CSS、JS 与资源全部放入 ZIP，仅保留一个 HTML 入口。
- 脚本使用包内 `.js` 文件，不使用内联脚本、onclick、eval/new Function、WASM 或 Worker。
- 容器支持 HTML/CSS/JS、Canvas/WebGL 和本地存储，不需要小游戏专用引擎。
- 图标支持 PNG/JPG/JPEG，官方指南截图建议 1:1、不超过 5 MB。名称、Slogan 在该截图中各最多 14 字。

因此静态离线小游戏适用，动物直播、外部 AI API 与本地 Ollama 服务不适用于该容器。桌面版不能原样上传，也不能用外部跳转替代小工具内应有的功能。
