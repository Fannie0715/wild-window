## 平台限制

[官方容器规范（更新于 2026-08-11）](https://fe-video-qc.xhscdn.com/fe-platform-file/104101b8323q4m0uaga06277180ac7t8006ptl0e12ek1g)：

- 必须完全离线，不能请求外网、加载外部图片/字体、嵌入 iframe/object。
- HTML、CSS、JS 与资源全部放入 ZIP，仅保留一个 HTML 入口。
- 脚本使用包内 `.js` 文件，不使用内联脚本、onclick、eval/new Function、WASM 或 Worker。
- 容器支持 HTML/CSS/JS、Canvas/WebGL 和本地存储，不需要小游戏专用引擎。
- 图标支持 PNG/JPG/JPEG，官方指南截图建议 1:1、不超过 5 MB。名称、Slogan 在该截图中各最多 14 字。

因此动物直播版不能原样上传。离线版必须明确展示为小游戏，不能伪装成实时直播或模型识别。

## 上传流程

[创作者服务中心](https://creator.xiaohongshu.com/) → Builder Hub → 小工具 → 上传 ZIP、填写名称/Slogan/图标 → 提交审核。审核通过后在手机 App 发布笔记时通过“插件/组件 → 小工具”挂载。

ZIP 根目录放 `index.html` 是本项目的保守兼容打包方式；当前未核实官方最大 ZIP 尺寸或明确的根目录文件命名限制。以实际上传表单校验为准。

[官方活动原帖](https://www.xiaohongshu.com/explore/6a83207d000000002702267a)。投稿需保持公开到结果公布，作品须原创；改编作品应标明出处。小游戏不附带外部跳转链接，避免在平台内添加未经核实的引流方式。
