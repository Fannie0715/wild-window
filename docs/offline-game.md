# Global Wildlife Monitor · 全球动物监控：观察挑战（离线小游戏）

这是一个独立的中文 HTML 小游戏，是直播网页的独立离线版本。无需构建、依赖安装、网络请求或登录。打开 `index.html` 即可开始。

## 发布文件

只把下列 5 个文件放在压缩包根目录，保持文件名和相对路径：

- `index.html`：唯一入口，移动端布局与辅助功能标记。
- `style.css`：炭黑、橄榄荧光色、取景框与静态扫描线。
- `game-core.js`：动物线索、洗牌、不可变游戏状态与计分逻辑。
- `game.js`：页面交互、反馈、结果、重玩和最佳记录。
- `icon.svg`：功能性对焦图标，无外部资源。

本 README 和 `tests/` 是开发交付说明，不应进入发布压缩包。

## 行为

直接进入第 1 轮。每局恰好 6 轮，大象、斑马、长颈鹿、信天翁、大熊猫、麋鹿各出现一次，顺序随机。每轮 3 个不重复的动物选项，其中 1 个正确，选项顺序随机。没有倒计时。

首次选择即锁定：答对加 1 分，答错不扣分；正确答案始终标出，同时出现一条动物知识。用户点击“下一条线索”继续，第 6 轮反馈后点击“查看观察记录”进入结果。结果包含总分、鼓励语、6 条作答记录及错题知识。重玩清零本局并重新洗牌；随机结果偶尔相同属于正常行为。

完成一局时尝试把最高分保存在本机 localStorage。读取、校验、写入均有异常兜底；存储受限不会中断游戏，并显示无法保存的提示。没有收集个人数据或发送数据。

## 约束

所有脚本均通过外部本地 `.js` 加载，无内联脚本/事件属性，无 iframe、网络调用、eval、new Function、WASM 或 Worker。使用系统字体；无视频、AI 识别或模拟实时摄像头。页面 CSP 禁止网络连接、嵌入框架、对象与 worker。按钮至少 55px 高。支持键盘与可见焦点、反馈播报、下一轮标题焦点、减少动态效果偏好。

## 验证

在此目录执行：

```sh
node --test tests/game-core.test.cjs
node --check game-core.js
node --check game.js
```

测试覆盖 100 个种子的每局动物唯一性、三个选项完整性，轮次/选项洗牌，未作答不可前进、非法答案、重复作答锁定、正确和错误计分、完整六轮的混合得分、满分/零分、结束后状态锁定、重玩清零、洗牌输入保护和随机源校验，以及入口和本地资源的离线结构约束。

本次验证使用 Node 逻辑与静态检查，未做真实浏览器、手机 WebView 或小红书开发者平台的渲染/平台审核测试。平台最终接入需在其预览环境检验。
